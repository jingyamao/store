# 历史记忆离线评测设计

## 目标

让作者用已核对的章节问题集重复检查历史记忆的准确性，看到版本改动导致哪些事实回溯正确或错误。评测只读本地书籍和题目集，不调用模型。

## 输入与规则

- YAML 题目集包含 `version: 1` 和非空 `cases`。每题有唯一 ID、目标章节、实体集合与 ID、动态字段、预期值；可附预期事实来源。
- 目标章节指“开始写这一章之前”，因此只读取更早章节的已确认事实。字段限制与章节记忆一致，避免用任意路径读取私有文件。
- `expected: null` 表示该字段此时应未知或不存在，不等同于空字符串、`false` 或空数组。
- 评测时先校验整个题目集，再只读取一次 Bible、sync 提案、手工历史与章节列表。每题使用同一回溯逻辑。若书籍中的提案损坏，明确失败，不输出看似可信的通过率。
- 每题输出实际值、预期值、使用的事实来源、是否通过及回溯告警；汇总总通过率与各字段通过率。可选 `--output` 写入书籍目录外的 JSON 报告；禁止覆盖题目集和书籍文件，已有报告需要 `--force`。有失败题目时命令退出码为 1。

## 边界

本阶段测结构化事实回溯，不测模型生成质量或语义检索命中率。30 章真实题目集需要作者提供真实或有授权的稿件；工具先提供可复现的评测格式和示例。

## 验证

测试涵盖过去/未来事实、字段值与来源断言、未知值、输入校验和报告汇总。使用临时书籍与本地数据，不调用模型。
